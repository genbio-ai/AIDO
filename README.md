# Research Overview

GenBio AI is building AIDO, an AI-Driven Digital Organism: a system of integrated multiscale foundation models for predicting, simulating, and programming biology at all levels, from molecules to cells to individuals.

Our first virtual cell, **AIDO Cell**, is a world model that simulates a cell's biology from molecules to whole-cell behavior. Join the waitlist for early access to the closed alpha.

* 📝 Read the announcement: [AIDO Cell: A General-Purpose Simulator for Cell Biology](https://genbio.ai/blog/)
* 🧬 Join the waitlist: [Sign up here](https://genbio.ai/)

## Previous-Generation Models

Our previous-generation models were essential to our investigation of how large-scale machine learning can be applied across biology. These models are now open sourced under a non-commercial and academic license. Originally released as AIDO.\_\_\_\_\_, they are now recategorized into our open source ecosystem under GB.\_\_\_\_, while AIDO remains our flagship biology simulator. The latest version, AIDO Cell, is now in closed alpha access.

**Note on naming:** GB.Cell (formerly AIDO.Cell) is the single-cell foundation model below. It is distinct from AIDO Cell, our new virtual cell world model described above.

Our initial stage-1 release in 2024 included the following foundation models:

* AIDO.DNA → Now GB.DNA
* AIDO.RNA → Now GB.RNA
* AIDO.Protein → Now GB.Protein
* AIDO.StructureTokenizer → Now GB.StructureTokenizer
* AIDO.Cell → Now GB.Cell

These pretrained foundation models, and the corresponding downstream utility layer for adapting them and generating downstream task models, remain available via the [GB.ModelGenerator](https://github.com/genbio-ai/ModelGenerator) repository and as [Hugging Face model checkpoints](https://huggingface.co/genbio-ai).
